# Участие в разработке

[English](CONTRIBUTING.md) · **Русский**

Issues и pull requests приветствуются.

Сохраняйте изменения в рамках надёжной организации окружения Codex. У нового правила должен быть один ясный владелец; не дублируйте изменяемое состояние в нескольких файлах.

Перед созданием pull request выполните:

```bash
python -m unittest discover -s tests -v
python scripts/inspect_codex_project.py --cwd .
```

Не добавляйте в фикстуры и примеры учётные данные, личные пути, клиентские данные, логи сессий и приватные заметки окружения.
