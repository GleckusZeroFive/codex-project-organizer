# Минимальный пример parent → subagents

[English](README.md) · **Русский**

Копируйте только те части, которые нужны вашему проекту:

```text
project/
├── AGENTS.md
└── .codex/
    ├── config.toml
    └── agents/
        ├── explorer.toml
        └── reviewer.toml
```

Родительский агент отвечает за границы задачи, решения, разрешения, интеграцию результатов и финальный ответ. Дочерние агенты выполняют ограниченные задачи только на чтение и возвращают доказательства.

В файлах ролей намеренно нет `model` и `model_reasoning_effort`: они наследуют настроенные значения или параметры родителя. Закрепляйте их только тогда, когда у роли есть устойчивая причина отличаться.

Проектная конфигурация `.codex` и агенты загружаются только для доверенного проекта. Проверьте эти файлы до того, как доверять репозиторию.
